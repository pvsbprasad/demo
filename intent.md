# Sourcing Negotiation Agent Extension — Sourcing Category Detection

Extend the Sourcing Negotiation Agent to detect and display the procurement category at the start of every response, and append an AI-generated disclaimer with date/time to every response.

## Business Challenge

The procurement team uses the Sourcing Negotiation Agent to analyze bids and recommend negotiation strategies. There is no structured indication of which procurement category is being analyzed, and responses lack a standardized AI-generated disclaimer. The goal is to extend the agent so that:
1. Every response starts with a structured "Sourcing Category" block identifying the detected category, confidence level, registered instruction set, and evaluation lens.
2. Every response ends with the note "THIS RESPONSE WAS GENERATED BY AI AGENT" including the date and time it was created.

### Key findings
- The Sourcing Negotiation Agent (`sap.agtnego:agent:sourcing-negotiation-agent:v1`) is extensible and supports instructions, tools, and hooks.
- The `enable_agent_extension_n8n_hooks` feature flag is `false` — n8n pre/post hooks cannot be configured in this environment.
- The AI disclaimer and timestamp requirement will be addressed via the instruction extension, instructing the agent to append the disclaimer itself.
- The Sourcing Category Detection block is fully achievable via instruction extension.
- SAP Ariba Sourcing and S/4HANA Cloud cover the underlying sourcing capabilities.

## Recommendations

### Instruction-Only Agent Extension

#### Executive Summary

Extend the agent via instruction to add category detection and AI disclaimer.

#### Recommended Solution

Create an agent extension targeting `sap.agtnego:agent:sourcing-negotiation-agent:v1` (version 1.0.0) that adds:
1. A Sourcing Category Detection instruction block (category, confidence, registered instruction set, evaluation lens) at the start of every response.
2. An instruction to end every response with "THIS RESPONSE WAS GENERATED BY AI AGENT" plus the current date and time.

The n8n pre/post hooks requested are not available because `enable_agent_extension_n8n_hooks = false` in this environment.
