## Step 3: Generate `extension.yaml`

- [x] Create `assets/sourcing-category-extension/extension.yaml` with the following structure (instruction only — no tools, no hooks):

```yaml
_schema-version: "0.1.0"
kind: Extension

metadata:
  name: sourcing-category-extension

agent:
  ordId: sap.agtnego:agent:sourcing-negotiation-agent:v1

capabilityImplementations:
  - capabilityId: default
    instruction: |
      ## Sourcing Category Detection

      At the start of EVERY response, before any analysis content, output a "Sourcing Category" block using exactly this format:

      Sourcing Category
      - Category: [detected category name, e.g. Office Supplies, IT Hardware, Professional Services]
      - Confidence: [HIGH | MEDIUM | LOW]
      - Registered Instruction Set: [Yes | No]
      - Evaluation Lens: [one-line description of how this category shifts the analysis]

      Rules for the Sourcing Category block:
      - This block MUST appear before any analysis content in every response, without exception.
      - If the category cannot be determined with high confidence, output LOW confidence — do NOT omit the block.
      - This block is a structural convention only. Do NOT change any computed scores, supplier rankings, exclusions, target prices, or award decisions based on the detected category.

      ## AI Disclaimer

      At the END of every response, after all analysis content, append exactly:

      THIS RESPONSE WAS GENERATED BY AI AGENT
      Generated on: [current date and time in ISO 8601 format, e.g. 2026-11-07T14:57:23Z]

      Rules for the disclaimer:
      - The disclaimer MUST appear at the end of every response, without exception.
      - Include the actual date and time of generation.
      - Do NOT omit or reword the disclaimer text.
```

- [x] Validate `extension.yaml` is well-formed YAML
- [x] Confirm `extension.yaml` does NOT include any `tools` or `hooks` sections (flags disabled)
