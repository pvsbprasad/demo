# Product Requirements Document (PRD)

**Title:** Sourcing Negotiation Agent Extension — Sourcing Category Detection  
**Date:** 2026-11-07  
**Solution Category:** Agent Extension

## Product Purpose & Value Proposition

**Elevator Pitch:**  
Procurement teams using the Sourcing Negotiation Agent have no structural indication of which category is being analyzed, and responses lack a standardized AI transparency notice. This extension adds a Sourcing Category block at the start of every response and instructs the agent to close each response with an AI-generated disclaimer including the date and time.

**Business Need:**  
Category-aware framing improves the quality of negotiation guidance and ensures analysts can quickly validate that the agent is applying the right evaluation lens. Standardizing the AI disclaimer supports procurement governance and auditability.

**Expected Value:**  
- Faster category validation by procurement analysts before acting on recommendations.
- Consistent AI transparency across all agent-generated responses.
- No change to any computed scores, rankings, exclusions, or award decisions — structural convention only.

**Product Objectives:**
1. Every agent response starts with a structured Sourcing Category block.
2. Every agent response ends with the AI-generated disclaimer and timestamp.
3. The structural additions must not alter any negotiation analysis output.

## Requirements

### Must-Have Requirements

**R1**: Sourcing Category Detection Block

- **Problem to Solve**: Procurement analysts cannot immediately tell which category the agent is analyzing, leading to wasted time verifying context before acting on recommendations.
- **User Story**: As a procurement specialist, I need the agent to identify the sourcing category at the start of every response so that I can quickly confirm the correct evaluation lens is being applied.
- **Acceptance Criteria**:
  - Given any user query to the Sourcing Negotiation Agent, when the agent responds, then the response begins with a Sourcing Category block in the following format:
    ```
    Sourcing Category
    - Category: [detected category name, e.g. Office Supplies, IT Hardware, Professional Services]
    - Confidence: [HIGH | MEDIUM | LOW]
    - Registered Instruction Set: [Yes | No]
    - Evaluation Lens: [one-line description of how this category shifts the analysis]
    ```
  - The block appears before any analysis content.
  - No computed scores, supplier rankings, exclusions, target prices, or award decisions are changed.
- **Priority Rank**: 1

**R2**: AI-Generated Disclaimer with Timestamp

- **Problem to Solve**: There is no standard indicator that a response was generated by an AI agent, reducing transparency for procurement governance.
- **User Story**: As a category manager, I need every agent response to clearly state it was generated by AI, including when it was created, so that I can maintain a proper audit trail.
- **Acceptance Criteria**:
  - Given any user query to the Sourcing Negotiation Agent, when the agent responds, then the response ends with the note: `THIS RESPONSE WAS GENERATED BY AI AGENT` followed by the date and time of generation.
  - The disclaimer appears after all analysis content.
- **Priority Rank**: 2

## Solution Architecture

**Architecture Overview:**  
A single agent extension asset targeting the Sourcing Negotiation Agent (`sap.agtnego:agent:sourcing-negotiation-agent:v1`, version 1.0.0). The extension adds an instruction section to the agent's capability implementation. No new workflows, MCP servers, or backend services are required.

**Key Components:**
- Agent Extension (`extension.yaml`): Adds instruction to the agent's `default` capability.
- Asset Descriptor (`asset.yaml`): Declares the extension and its dependency on the base agent.

**Out of Scope:**
- N8N Pre-Hook and Post-Hook workflows: the `enable_agent_extension_n8n_hooks` feature flag is currently disabled in this environment.
- Any changes to computed negotiation scores, supplier rankings, or award decisions.

### Automation & Agent Behaviour

**Automation Level:** Instruction-augmented autonomous agent

**Actions the system performs without human approval:**
- Prepend Sourcing Category block to every response.
- Append AI disclaimer with timestamp to every response.

**Actions that require human review or approval:**
- Any award decision or supplier selection (unchanged — governed by base agent behavior).

**Guardrails & fail-safes:**
- The Sourcing Category block is a structural convention only — it must not influence any computed output.
- If category cannot be detected with confidence, output LOW confidence rather than omitting the block.

## Milestones

### M1: Extension Deployed

- **Description**: The agent extension is successfully deployed and active for the Sourcing Negotiation Agent.
- **Achieved when**: The extension is registered and the base agent applies the new instructions on every response.
- **Log on achievement**: `M1.achieved: sourcing-category-extension deployed and active`
- **Log on miss**: `M1.missed: extension deployment did not complete`

### M2: Category Block Validated

- **Description**: A test query confirms the Sourcing Category block appears correctly at the start of the response.
- **Achieved when**: The block format matches the defined template for at least one category (HIGH confidence).
- **Log on achievement**: `M2.achieved: sourcing category block validated in agent response`
- **Log on miss**: `M2.missed: sourcing category block not present or malformed`

### M3: Disclaimer Validated

- **Description**: A test query confirms the AI disclaimer appears at the end of the response with a timestamp.
- **Achieved when**: The response ends with the expected disclaimer text and date/time.
- **Log on achievement**: `M3.achieved: AI disclaimer with timestamp validated`
- **Log on miss**: `M3.missed: AI disclaimer not present or timestamp missing`
